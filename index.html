  • Class 9–10: Contemporary India (समकालीन भारत)
  • Class 11: Fundamentals of Physical Geography (सर्वाधिक महत्वपूर्ण)

  • Class 12: Introductory Macroeconomics (समष्टि अर्थशास्त्र)
